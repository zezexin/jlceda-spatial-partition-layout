# 图幅坐标系与分区尺寸规则

## A3（已校准模板）

- 有效安全区：X `40..1615`，Y `200..1145`（宽1575、高945）。
- 标题栏禁布区：X `945..1645`，Y `7..190`。
- 参考九宫格列：`40..540`、`570..1070`、`1100..1615`。
- 参考九宫格行：`200..500`、`530..830`、`860..1145`。
- 功能区之间至少间隔50 units；芯片/连接器周围预留约20%空间给走线与网络标签。

## A4/A5与其他模板

本技能没有把A3坐标自动缩放到A4/A5的规则。每次项目必须先从当前页 `titleBlockData`/页面属性读取图幅、边框、有效安全区和标题栏禁布区；若API没有返回这些值，则基于当前EDA页面的真实边框校准，并让用户确认。未校准前不得开始放置元件或执行布局脚本。

图幅应记录为明确的 `sheet_size` 字段；多页项目逐页记录页码、页面UUID和安全区。新建页面后重新读取其属性，不能假设继承坐标必然一致。

## 标题锚点（嘉立创EDA环境实测）

`sch_PrimitiveText.create(x, y, ...)` 的 `(x,y)` 是文字左下角，文字纵向占据 `y..y+fontSize`。

- `x_title = x_min + 10`
- `y_title = y_max - (fontSize + 10)`；24号字对应 `y_max - 34`
- 必须验证 `x_title >= x_min + 10`、`x_title + text_width <= x_max - 10`、`y_title >= y_min + 10`、`y_title + fontSize <= y_max - 10`
- 优先采用EDA文本实际包围盒；没有实际宽度时采用保守估算，中文按接近1em而不是0.62em计算。

## 时序规则

坐标矩形可以在内部预演阶段生成，但实际绘制的功能区框和标题必须等器件放置及连线完成后，根据实际包围盒重新计算。若实际内容比预演大，应修改布局或增加页面，不能让框压住内容。
