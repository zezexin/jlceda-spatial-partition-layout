# 参考原理图审阅清单（用户提供的人工绘制示例）

本文记录从参考截图得到的视觉布局经验，并将它们转成自动布局 Agent 可重复执行的审阅步骤。截图中直接能看见功能区标题和相对拥挤的排版；实际电气关系仍必须从工程文件、网表、BOM 和 ERC 获得，不能凭截图推断为已验证。

## 1. 截图中可见的功能区

可见标题包括：USB-C、CHARGE、DC/DC、MCU/C61、I/O、KEY、KEY-RST、PSW、MIC、KEY-ADC、32.768KHz、Micro SD、EPD。它们可作为审阅入口，不应被硬编码成所有项目都必须使用的功能区。新项目要先依据真实电路功能分组。

## 2. 按优先级执行的视觉审阅

### P1：解决最密集、最影响阅读的区域

- **MCU 与 I/O 映射**：检查 MCU 周围器件、引脚名称、网络标签及中央 I/O 列表是否互相重叠或过于靠近。必要时把主控局部电路与信号索引表分开，或拆到不同页；不能通过隐藏引脚名/网名来制造“清爽”假象。
- **EPD/高引脚数连接器**：为连接器本体、引脚编号、网络标签和扇出留出独立空间。检查多条信号是否在视觉上难以追踪，整理电源、SPI、控制和状态信号；跨功能区/跨页用一致的 Port/Flag 名称桥接。
- **页数与阅读比例**：先在预演阶段估计全部标签、端口和器件包围盒。A4 页面若在正常阅读比例下无法辨认，应比较 A3 和多页两种方案，不将单页目标置于可读性之上。

### P2：让电源路径容易追踪

- 将 USB-C 输入、输入保护、充电管理、电池相关节点、电源转换和输出电源按功能流向整理。
- 检查 VBUS、VBAT、VOUT、+3V3、GND 等网络的标签是否清晰、一致且落在正确网络上；这里只列出截图可能涉及的示例名称，实际网名以项目数据为准。
- 同功能块内部优先短连线；跨区连接使用同名 Port/Flag，避免导线穿过无关模块或覆盖其他标签。
- 不要让分区框在视觉上遮断供电链路，也不要把分区矩形当作电气边界。

### P3：核对容易被相似标题混淆的模块

- **KEY / KEY-RST / KEY-ADC**：根据实际连接区分普通 GPIO 按键、复位/启动电路、ADC 电阻梯按键等职责（仅作为可能的命名方案）。确认功能后，统一标题格式；不得仅凭名字接近而把电气功能不同的电路合并。
- **32.768 kHz**：将晶体和它的相关负载/连接作为局部电路审阅，保持信号路径短且命名清楚；是否为 RTC 时钟、器件引脚和元件值必须从实际原理图核实。
- **Micro SD**：卡座、相关辅助器件与接口信号放在容易理解的区域，核对 SPI/控制信号两端网络名和端口一致。不可猜测截图中没显示的连接。
- **MIC 等模拟信号区**：清楚标识输入、偏置/供电和输出网络，并与数字接口在原理图语义上合理分组。视觉分区本身不证明 PCB 上的噪声隔离或布线正确。

## 3. 统一格式规则

- 统一标题语言、命名结构、字号、对齐方式与内边距；中英混合可用，但项目内应一致。
- 功能区按信号流、模块关系或接口方向组织；避免把网络标签放在框线、引脚号或其他标签上。
- 芯片和连接器附近预留标签与走线空间；若加入 Port/Flag 后模块溢出，重新规划区域或加页。
- 可见分区框必须在器件和电气连线完成后绘制，并按实际包围盒扩展；分区框不得成为放置器件的硬限制，以致把电路挤坏。
- 所有框色按 `SKILL.md` 中用户指定的颜色池随机选择。框色仅作视觉分组，不代表网络类型、电压等级或电气属性。

## 4. 审阅输出格式

审阅结果至少包含：

1. **可见事实**：截图中实际能辨认的功能区、可能拥挤的区域、标题和标签样式。
2. **布局建议**：按 P1/P2/P3 排序，写清楚要扩大哪个区域、哪类标签需要避让、是否考虑多页。
3. **待数据验证项**：需要 BOM、网表、原理图工程或器件数据手册确认的连接、位号、参数与网络语义。
4. **布局变更影响**：任何移动或加页是否需要重新连接、重新核位号，并重新运行 ERC/网表检查。

## 5. 不得越界的结论

- 不能只凭截图说 BOM 位号完全一致。
- 不能只凭线条的视觉接触说两个引脚电气相连。
- 不能仅凭标题或模块位置推断具体拓扑、器件参数或 MCU 引脚功能。
- 不能声称通过 ERC、网表或实际 EDA 页面验收，除非确实运行过并检查了对应输出。
