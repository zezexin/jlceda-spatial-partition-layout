# 跨功能区/跨页面信号连接规范

## 规则

1. 同一功能区内、从器件到器件的局部连接直接布线。
2. 跨功能区或跨页面信号禁止用一条长导线穿越其他功能区。
3. 在逻辑源端和目的端分别使用同名 Port 或 Flag；使用后要通过实际网表/ERC确认两端属于同一网络。
4. 不得仅凭标签名字相同就推定已经电气连通；检查端口类型、网络名拼写、方向和连接点。
5. 规划阶段可以把计划中的分区边缘作为路由参考，但不能提前绘制可见分区框。所有电气连线完成并通过连通性初检后，再按真实占用边界画框和标题。

## 嘉立创EDA版本说明

项目记录中嘉立创EDA 3.2.186 的 `createNetLabel` 曾发生无法 resolve 的情况。因此在此环境中优先使用 Port/Flag，并用网表/ERC验证；其他版本需先做最小实验确认行为。

## 检查记录字段

跨区/跨页网络可在终检JSON中记录：

```json
{"net": "SPI_SCLK", "cross_region": true, "cross_page": false, "method": "port"}
```

`method` 仅接受 `port` 或 `flag`。如果 `cross_region` 或 `cross_page` 为真而 `method` 是 `direct`/缺失，终检失败。
